# vietcong-web-mp — Red Dawn theme

Browser multiplayer prototype. Dusk jungle mood inspired by the Red Dawn theme.

## Theme
Warm low sun, brown-green fog, dark trunks, muted canopy. UI in amber on black.

## Optional audio
Place your own `red-dawn.mp3` next to `index.html`. The game will try to loop it at low volume. Do not commit copyrighted audio to the public repo.

## Weapons & power-ups
Rifle / Shotgun / Sniper. Health, damage, and speed pickups.

## Run
```bash
npm install
npm run server
npm start
```
