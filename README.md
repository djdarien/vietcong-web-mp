# vietcong-web-mp

Browser multiplayer Vietcong-style FPS. Procedural only.

## Phase 2 features
- Name tags above players
- Deathmatch scoring (shoot, 25 dmg, kill = 1 point, 3s respawn)
- Map voting (Jungle / River / Docks) — majority switches map
- Server-side distance check on hits
- Scoreboard + kill feed

## Quick start
```bash
git clone https://github.com/djdarien/vietcong-web-mp.git
cd vietcong-web-mp
npm install
npm run server
npm start
```
Others join `http://HOST-IP:3000`.

## Controls
Desktop: WASD, mouse, click to shoot
Mobile: joystick + FIRE
Vote buttons bottom-right. Chat bottom-left.
